\bmhead{Data availability} The source datasets are publicly accessible from the sources below. The paired-validation supplement contains metrics, article-selection identifiers and configuration records rather than article text. The copies used were downloaded from Kaggle for ISOT (\url{https://www.kaggle.com/datasets/rahulogoel/isot-fake-news-dataset}) and WELFake (\url{https://www.kaggle.com/datasets/studymart/welfake-dataset-for-fake-news}) and from a GitHub mirror for McIntire (\url{https://github.com/joolsa/fake_real_news_dataset}, file \texttt{fake\_or\_real\_news.csv}, 6,335 articles); the original publications are cited in Section~\ref{sec:data}. The validation result files, recorded configuration files, seed assignments and article-selection manifests are supplied in the supplementary research archive; the code repository contains the underlying experimental pipeline.
\bmhead{Code availability} Code for the audit, interventions, experiments and analysis: \url{https://github.com/abiroh-p/ERM}.
\bmhead{Computing environment and software} The document-paired Kaggle validation recorded Python 3.13.16, NumPy 2.1.3, pandas 2.3.3, scikit-learn 1.6.1 and SciPy 1.16.3. Transformer records additionally identify PyTorch 2.11.0+cu130 and Transformers 5.20.2. Both GPUs ran independent fine-tunes. The cache records spaCy \texttt{en\_core\_web\_sm} as the entity method; a cache identity is not a complete reconstruction of its historical generation environment. These recorded new-run versions supersede the old draft's unsupported version attribution for this validation only. Archived DistilBERT library versions were not recorded. The original TF-IDF environment remains incompletely verified; the archived later Kaggle runs have separate configuration records and are not merged with the new protocol.
